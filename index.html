Design suggestions (for discussion)

  • Card-first home — scrap items as soft cards (photo, status chip); maps cleanly to RN FlatList.
  • Green primary / blue secondary — primary CTAs green; chat/assign secondary blue.
  • One collector transaction screen — Verify → Rate → Amount → Paid → Complete.
  • Admin sidebar — same tokens as apps for brand consistency.
  • Soft green wash backgrounds — light, professional, not dark/purple AI look.
  • Language on register + Settings only — not in Header (keeps home clean).
  • Landing page — Phase 2 after this review.
